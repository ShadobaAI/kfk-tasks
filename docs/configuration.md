# Настройка

## Корень рабочей области

`KAFKA_PROJECTS_ROOT` — единственный обязательный параметр пути. Он указывает на
родительский каталог, содержащий `adapter`, `conversion`, `tasks`, `tests` и
`tools`.

Не добавляй машинно-зависимое значение этой переменной в Git.

## Карта репозиториев

[repositories.example.json](../config/repositories.example.json) задаёт
стабильные имена репозиториев и относительные пути. Если локальная структура
отличается, скопируй файл в `config/local.json` и измени значения. Локальный
файл исключён из Git.

Канонические документы сервер ищет по пути:

```text
<KAFKA_PROJECTS_ROOT>/tasks/memory-bank
```

Если переменная окружения не задана, путь `tasks/memory-bank` определяется
относительно установленного пакета или editable-установки.

## Кодировка

- Markdown хранится в UTF-8.
- Атомарная запись использует окончания строк LF.
- Пути и содержимое поддерживают кириллицу.
- Канонические ссылки используют прямые слеши даже в Windows.

## Секреты

Memory Bank не содержит настроек токенов или учётных данных. Данные доступа к
брокерам, GitHub, уведомлениям и внешним журналам должны храниться в
предназначенных для этого секретах среды развёртывания.
