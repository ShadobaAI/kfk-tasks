# VS Code и Obsidian

## VS Code

Открой репозиторий `tasks` или каталог `memory-bank`. Markdown Preview
поддерживает обычные относительные ссылки без специального синтаксиса
расширений.

Репозиторий рекомендует, но не требует:

- Markdownlint;
- Red Hat YAML.

Пользовательские настройки и абсолютные пути в Git не добавляются.

## Obsidian

Открой `memory-bank/` как vault либо подключи его как каталог внутри другого
vault. Канонические ссылки используют стандартный Markdown:

```markdown
[Обзор архитектуры](architecture/overview.md)
```

Obsidian wiki links не требуются. Состояние рабочего пространства, мобильного
клиента, кеш, корзина и аналогичные персональные данные исключены из Git.

## Ручная проверка

1. Открой `memory-bank/README.md`.
2. Перейди по ссылкам к документам репозитория, архитектуры, спецификации и ADR.
3. Проверь переходы по ссылкам на заголовки в Markdown Preview.
4. Найди исходный кириллический идентификатор, например `кфкИнтеграция`.
5. После ручных изменений запусти валидатор.
